# ✈️ TravelGen - 旅プラン自動生成アプリ

行き先タイプ・日数・予算・季節・同行者・テーマを選ぶだけで、
日ごとのスケジュールから宿泊・季節のヒントまで自動生成するシンプルなWebアプリ。

## 使い方

`index.html` をブラウザで開くだけ。サーバー不要。

```
open index.html
```

## 機能

- 7種類の行き先タイプ（都市/ビーチ/山/温泉/海外アジア/欧州/米州）
- 日数・予算・季節・同行者・テーマに応じた行程生成
- 「別案を生成」ボタンで何度でもバリエーション
- プランをテキストでクリップボードにコピー
- スマホ対応のレスポンシブUI

## ファイル構成

- `index.html` - マークアップ
- `styles.css` - スタイル
- `app.js` - プラン生成ロジック
